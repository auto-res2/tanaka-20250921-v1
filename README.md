# C3PO: Constrained, Context-Aware Preference Optimisation for Large Language Models
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Preference fine-tuning is the work-horse for aligning large language models (LLMs), yet current practice hinges on two brittle scalar hyper-parameters: a global temperature β that rescales each preference margin and a target divergence κ that a heuristic controller attempts to enforce. Both must be grid-searched for every model, task, and surrogate loss, inflating energy cost while providing no guarantee that the fine-tuned policy remains inside a safety-critical trust region. Moreover, a single global setting is inherently sub-optimal—benign in-distribution prompts benefit from aggressive optimisation while risky or out-of-distribution inputs require tighter regularisation. We introduce C3PO, a drop-in, loss-agnostic wrapper that recasts preference fine-tuning as the constrained problem maximise E subject to KL(π‖π₀) ≤ κmax. C3PO combines (i) stochastic dual-ascent updates that provably converge to the optimal constrained solution, (ii) a 3 k-parameter context-aware network that predicts a per-sample β to adapt the KL leash to input risk, and (iii) an automatic rule that grows κmax online and removes manual schedules. Applied to logistic, exponential, or DiscoPOP losses, C3PO eliminates all sweeps. On dialogue, summarisation, sentiment, and safety benchmarks with Pythia-1.4 B and Mistral-7 B, a single C3PO run matches or surpasses the best of eight-point DPO and DiscoPOP grids while never violating the KL constraint and reducing GPU hours by roughly six-fold. Controlled stress tests confirm zero constraint breaches under reward perturbations, and ablations show that learned per-sample regularisation raises harmlessness on adversarial inputs.
