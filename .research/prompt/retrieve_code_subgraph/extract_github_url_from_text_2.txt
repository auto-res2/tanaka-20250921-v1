# Paper Outline
The core methodology is an LLM-driven objective discovery pipeline. It iteratively prompts an LLM (GPT-4) to propose new preference optimization loss functions in PyTorch code. These proposals are based on a problem description and in-context examples of previously evaluated loss functions and their performance metrics (e.g., MT-Bench scores). Each proposed objective function undergoes unit testing for validity, is then used to fine-tune an LLM, and evaluated on a predefined downstream task. The resulting performance metric is fed back to the LLM to refine its subsequent proposals. This process aims to discover general-purpose objective functions. The preference optimization task itself is framed as an offline supervised learning problem, minimizing a scalar loss function `f` over the log ratio difference `ρ` of policy and reference model likelihoods for chosen and rejected completions.
